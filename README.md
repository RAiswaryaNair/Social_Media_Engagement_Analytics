# Project Overview
This project analyzes social media engagement data to uncover patterns that drive user interaction and content performance. Using a dataset of 5,000 social media posts, the project applies data cleaning, exploratory data analysis (EDA), statistical techniques, and visualization to generate actionable insights.

# Objectives
Clean and preprocess raw data
Perform exploratory data analysis (EDA)
Analyze engagement metrics (likes, comments, shares, watch time)
Create a custom engagement score model
Visualize trends and patterns
Generate business insights

# Tools & Technologies
Python | Pandas | NumPy | Matplotlib | Seaborn | Plotly

# Dataset
The dataset contains 5,000 social media posts with:
User details (age, gender, country)
Post details (type, category, hashtags)
Engagement metrics (likes, comments, shares, impressions)
Sentiment information

# Steps followed
Imported and prepared data using Pandas
Cleaned missing values and standardized formats
Done data analysis
Applied statistical analysis (mean, median, variance, percentiles)
Created multiple visualizations (scatter, bar, line, heatmap, etc.)
Created interactive charts using Plotly

# Engagement Score Formula
Engagement Score = (Likes × 1) + (Comments × 2) + (Shares × 3)

# Key Insights
Video posts had the highest average likes (10,190) but only marginally ahead of Image (10,106) and Text (10,097) — a nearly 1.5% spread. 
Food  is the best performing category.
Brazil leads (1.54), notably ahead of the rest, followed by Australia (1.33) and France (1.15). USA and India trail at the bottom (0.58, 0.66) despite India having the highest average impression count — showing that reach and engagement rate are two different stories.

Across nearly every dimension tested (post type, age, verification, sentiment, device), differences in engagement were small and did not point to one dominant driver. The clearest standout finding was country-level engagement rate, where Brazil significantly outperformed larger-reach countries like the USA and India — suggesting engagement quality doesn't necessarily follow audience size or reach.

# Conclusion
This project demonstrates how data analytics can optimize social media strategies. By focusing on high-performing content types, audience segments, engagement can be significantly improved.
